## QymCAD: desktop parametric CAD

<p>
  <a href="https://github.com/QymIs-Tech/QymCAD/stargazers"><img src="https://img.shields.io/github/stars/QymIs-Tech/QymCAD?style=flat-square&logo=github" alt="Stars"></a>
  <a href="https://github.com/QymIs-Tech/QymCAD/releases"><img src="https://img.shields.io/github/v/release/QymIs-Tech/QymCAD?include_prereleases&style=flat-square&label=download" alt="Download"></a>
  <img src="https://img.shields.io/badge/platforms-Windows%20%7C%20Linux%20%7C%20macOS-4c6ef5?style=flat-square" alt="Platforms">

<a href="https://github.com/QymIs-Tech/QymCAD"><img src="https://github.com/QymIs-Tech/QymCAD/raw/HEAD/docs/help/img/window.png" alt="QymCAD window"></a>

Mechanical parts and assemblies: sketch → part → assembly. Precise B-rep geometry on OpenCASCADE, written in Rust. No cloud, no subscription, no account.

- **Sketching:** lines, arcs, splines, slots, text, with constraints and dimensions solved together
- **Parts:** extrude, revolve, sweep, loft, fillet, chamfer, shell, holes, patterns, booleans and more
- **Assemblies:** joints, limits and drives, degrees of freedom, interference check
- **Exchange:** STEP, STL, DXF, SVG

## Principles

- **Functional:** every device solves a real task. No features for the sake of features.
- **Modular:** any component can be swapped. Replace the part, not the device.
- **Repairable:** every device can be opened and fixed, with available parts, a clear design and open documentation.
